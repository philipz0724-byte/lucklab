# Memory World · 海边美术试玩样板 0.7a

这是经典掌机俯视像素风的**单场景可试玩美术样板**，用于确认人物比例、地图、动作与界面。完整故事版 V0.6 保留；这份工程专门从海边开始。

## 打开

1. 完整解压 ZIP，保留 `game.json` 与旁边的 `assets/`。
2. 在 GDevelop 打开 `game.json`。
3. 从唯一的 **Sea** 场景点击预览。

无需额外插件、联网素材或 API 密钥。原生工程使用本地资源；验证使用 GDevelop 5.6.284。

## 可以试玩什么

- 非力、孙天虎、死猪采用新的两三头身像素造型，保留偏高、宽壮、圆胖的区别。
- 自由行走，两位朋友沿走过的路线跟随。
- 靠近中间长椅按 E，三人坐下聊天；对话结束后可以继续安静坐着，按 E 起身。
- 左侧栏杆边吹海风，右侧栏杆边扔石头。可以选择扔远或随手扔近，显示轨迹和水面涟漪。
- Q 触发孙天虎打闹；按 1 侧身躲开，按 2 回嘴。打闹不锁定移动。
- 坐过长椅后有一次“天黑了看不见非力”的玩笑；死猪会催着去网吧。
- 海水使用独立动画。长椅、路灯、栏杆与人物分开绘制，按位置显示前后遮挡。
- 平时展示完整地图；对话时才出现对话框。

本样板只包含海边，不连接家门口、商场、烧烤和网吧地图；完整剧情仍在 V0.6 工程中。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 行走 |
| E / 空格 / Enter | 互动、继续对话；安静坐着时起身 |
| 1 / 2 | 当前选项；打闹时躲开 / 回嘴 |
| Q | 和孙天虎打闹，有短暂冷却 |
| J | 海边小记 |
| R | 重玩确认，起身并结束正式对话后可用 |

## 文件与实现

- `game.json`：原生 GDevelop 工程。
- `assets/`：87 个本地 PNG 资源。地图按 320×240 的逻辑像素设计，整数放大到 960×720；人物 24×32 逻辑像素，含四向行走、坐姿与互动动作。
- `logic/dialogue-and-following.js`：场景原生 JavaScript 事件的可读副本；修改副本不会自动更新 `game.json`。
- `screenshots/`：真实运行时截图，不是概念生成图。
- `VALIDATION.md`、`playtest-report.json`：验证范围与结果。

像素素材在原生资源制作代码中绘制，先前概念图用于方向参考，没有将整张概念图作为可交互地图。人物和场景为本项目原创表现。

## 当前简化

跟随为轨迹跟随，并非完整自主寻路和避让；拐弯或靠近时可能贴近。暂无音乐、音效、配音和跨次启动存档。这里的海边是回忆题材的概括式地图，不是实地测绘。
