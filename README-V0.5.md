# Memory World V0.5《青岛的那些夜晚》

非力、孙天虎、死猪的一个晚上。从齐东路附近家门口碰头开始，接上下班的朋友，吃串加餐、结账，去海边坐着吹风、扔石头，最后到网吧开黑，玩够了回家。

## 打开

1. 将 ZIP **完整解压**，不要只取出 `game.json`。它和 `assets/` 要放在一起。
2. GDevelop → 文件 → 打开 → 您的电脑，选择解压后的 `game.json`。
3. 从 **Home（家附近）** 场景点击「预览」。本版新增了开场，第一次请从 Home 开始。

这是原生 GDevelop 工程，包含 5 个真实场景、50 个本地图片资源和 75 条原生事件条目。无需额外插件、联网素材或 API 密钥。建议使用已验证的 GDevelop 5.6.284 或更新版。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 行走 |
| E / 空格 / Enter | 互动或继续对话 |
| 1 / 2 / 3 | 选择对话选项；兼容主键盘与数字小键盘 |
| J | 看今晚的小记 |
| R | 打开重玩确认；对话中不打断剧情 |

靠近人物或地点，看到 `[ E ]` 提示再互动。对话和结尾期间不能走动。

## 本版新增与修改

- **非力**：保留高个子体型，将脸、胳膊的肤色调深，增加有关晒黑、高个子的熟人互损对话。
- **孙天虎**：壮实的朋友；**死猪**：胖胖的保安朋友。名字进入人物标签、对话、小记和结尾。
- 新增 **齐东路附近的家门口** 地图。非力先和孙天虎碰头，两人再一起到商场接死猪。
- 烧烤有完整的 **点串 → 吃串 → 加单 → 吃加餐 → 结账**。可加十串羊肉串或一份烤馒头；可非力先结或三个人凑钱。已结账后不会重复结账。
- 移除合照，换成 **三个人在长椅坐一会儿**。人物使用独立坐姿；对话结束后起身回到原来的位置。坐着也会记录吹海风，不必重复跑两遍。
- 打水漂改为 **往无人的海面扔石头**：可用力扔远，也可随手扔近，显示抛物线和落水涟漪。可重复玩。
- 网吧结束后新增 **收队、道别、往齐东路附近回家** 的对话，以及独立的 **“今晚，收工。下次，老地方。”** 结尾画面。结尾可按 1 回到游戏自由逛，按 2 确认后重新开始。

## 流程提示

1. **Home**：和孙天虎说话 → 从右边去商场。
2. **Mall**：到商场门前和死猪说话 → 从右边去烧烤。
3. **BBQ**：烤炉点串 → 左侧圆桌吃 → 烤炉加单 → 圆桌吃加餐 → 烤炉结账 → 从右边去海边。
4. **Sea**：从长椅下方靠近，按 E 三个人坐一会儿。左侧可单独吹风，右侧可扔石头。坐过以后向右去网吧。
5. **Cafe**：在中间一排电脑旁选角色，再按 E 继续每个回合 → 一局结束 → 收队回家 → 结尾画面。

第二幕起均能从左边返回前一幕。本次运行中的碰面、入队、点餐、加餐、结账、坐椅子、扔石头和开黑进度会保留。结尾不要求玩扔石头。

## 仍保留的简化

- 朋友沿玩家已走过的轨迹跟随，新场景重新集合；尚无独立避让/自由寻路，集合或转弯时可能短暂贴近。
- LOL 是选位置和两回合文字互动，没有完整 MOBA 战斗。
- 暂无音乐、配音与跨次启动存档。关闭预览后重新开始；R 重玩也会清空本轮进度。
- 房屋、路口和海边是回忆题材的概括式像素场景，未声称复原真实家庭住址或精确街道。三个人的称呼与个人细节来自用户，对白是依此创作的游戏台词。

## 文件

- `game.json`：完整原生工程，修改玩法请编辑其中的场景事件。
- `assets/`：全部像素图片，均为相对路径。
- `logic/dialogue-and-following.js`：原生 JavaScript 事件的可读副本；仅修改该副本不会自动同步工程内的事件。
- `VALIDATION.md`、`playtest-report.json`：验证方法、范围与结果。

继续使用 V0.3 验证过的 Sprite、Text、TopDownMovement、SeparateFromObjects、NumberVariable、SetNumberVariable 和 Scene 结构。对话、坐姿、跟随、扔石头与结尾由 GDevelop 原生 JavaScript 事件补充，切场景仍走原生 Scene 动作。
