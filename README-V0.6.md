# Memory World V0.6《青岛的那些夜晚》

这一版让非力、孙天虎、死猪的性格出现在走路和小动作里。沿用 V0.5 的五张地图、点餐加餐结账、海边坐椅子与扔石头、LOL 选项和回家结尾。

## 打开

1. 将 ZIP 完整解压，保留 `game.json` 和旁边的 `assets/`。
2. 在 GDevelop 里打开解压后的 `game.json`。
3. 首次从 **Home（家附近）** 场景点击预览。

原生工程包含 5 个场景、58 个本地图片资源、75 条原生事件条目。无需额外插件、联网素材或 API 密钥。验证使用 GDevelop 5.6.284。

## 这版改了什么

- **非力肤色调浅**：依照“肤色偏黑，但没有上一版那么深”的反馈，调整所有方向、坐姿和新动作中的脸与胳膊。高个子体型保留。
- **孙天虎爱打闹**：碰面后走一段，会凑过来掐一下胳膊；海边坐过以后，有一次拍胳膊和“天黑了看不见非力”的玩笑。出现提示时按 1 侧身躲开，按 2 回嘴。只做熟人打闹，没有伤害、血量或打架任务。
- **随时再闹两句**：和孙天虎碰面后，在空旷处按 Q 可以再次触发打闹。按键有冷却，按住不会连续触发。海边肤色玩笑每轮只自动出现一次。
- **死猪惦记网吧**：下班、吃完串、到海边和进网吧都有对应的路上闲聊。海边依然会坐着歇会儿；最后一段去网吧时，他主动走到前面。进网吧后会沿过道走向电脑。
- **闲聊不打断走路**：这些路上对话不锁定玩家；看到地点提示照常按 E，正式互动会立即接管。打闹的动作结束后自动恢复，不会把玩家推到障碍物里。
- **人物口气统一**：替换原来让死猪主动喜欢散步、不急着去网吧的台词。结尾仍然收队回家，但他会先提议“再来一把”。

这几处生活细节来自用户；具体对白与动作是据此创作的游戏表现。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 行走 |
| E / 空格 / Enter | 互动或继续正式对话 |
| 1 / 2 / 3 | 选择当前对话选项；兼容数字小键盘 |
| 打闹提示时 1 / 2 | 侧身躲一下 / 回嘴 |
| Q | 和孙天虎闹两句（碰面后、正式对话外可用，有冷却） |
| J | 今晚的小记 |
| R | 重玩确认；正式对话中不打断剧情 |

不回应打闹也能继续走，几秒后会自然收尾。人物性格互动不影响通关条件，也不额外要求收集回忆。

## 主线

1. **Home**：齐东路附近和孙天虎碰面 → 右侧去商场。碰面后往右走一段，会出现第一次打闹。
2. **Mall**：和商场门前的死猪说话 → 右侧去烧烤。
3. **BBQ**：烤炉点串 → 左侧圆桌吃 → 烤炉加单 → 圆桌吃加餐 → 烤炉结账 → 右侧去海边。
4. **Sea**：从长椅下方靠近，三个人坐一会儿。左侧可吹风，右侧可扔石头；坐过后从右侧去网吧。
5. **Cafe**：中间一排电脑旁选位置 → 两回合开黑 → 一局结束 → 收队回家 → 正式结尾画面。

结尾按 1 回到游戏自由走走，按 2 确认后重玩。从第二幕起可从左侧返回。人物入队、加餐、结账、坐椅子、扔石头和开黑进度跨场景保留；自动闲聊是否出现过也会保留。

## 仍保留的简化

- 普通跟随沿玩家走过的轨迹；这一版加入平滑靠近。孙天虎的小动作是短距离靠近，死猪去电脑使用预设的过道路线。尚无完整的 NPC 自主寻路和彼此避让，转弯或集合时可能贴近。
- LOL 是选位置、两回合文字互动，没有完整 MOBA 战斗。
- 暂无音乐、配音与跨次启动存档。关闭预览后重新开始；确认 R 重玩会清空本轮故事与闲聊记录。
- 场景为概括式像素表现，不是精确复原真实街道或家庭住址。

## 工程文件

- `game.json`：原生工程。玩法和对白写在场景事件中。
- `assets/`：全部本地像素资源。
- `logic/dialogue-and-following.js`：JavaScript 事件的可读副本；只修改副本不会同步工程里的事件。
- `VALIDATION.md`、`playtest-report.json`、`personality-test-report.json`：验证范围和结果。

继续保留 V0.3 已验证的 Sprite、Text、TopDownMovement、SeparateFromObjects、NumberVariable、SetNumberVariable 和 Scene 结构。对话、人物互动、坐姿、跟随、扔石头和结尾由 GDevelop 原生 JavaScript 事件补充；场景切换走原生 Scene 动作。
