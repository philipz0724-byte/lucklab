# Memory World V0.7 · 青岛的那些夜晚

非力、孙天虎、死猪的一个普通晚上。这版把已试玩认可的海边像素风，统一到齐东路附近、商场、烧烤、海边和网吧五张地图中。

## 打开试玩

1. 完整解压，保留 `game.json` 与旁边的 `assets/` 文件夹。
2. 在 GDevelop 打开 `game.json`。
3. 从 **Home** 场景点击预览，按右上方提示走完整个晚上。

工程自带全部图片，无需额外插件、联网素材或 API 密钥。验证引擎为 GDevelop 5.6.284。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 行走 |
| E / 空格 / Enter | 互动、继续对话；安静坐着时起身 |
| 1 / 2 / 3 | 选择当前对话选项 |
| Q | 和孙天虎打闹；1 躲一下，2 回嘴，可继续走动 |
| J | 看今晚的小记 |
| R | 确认是否重新开始 |

对话和坐着时暂停移动。坐椅子的对话结束后不会自动起身，想走时按 E。

## 今晚的路线

- **齐东路附近**：先和孙天虎碰头，再一起向右去接死猪。
- **商场**：走近门口的死猪，等他交班后，三个人一起去吃串。
- **烧烤摊**：烤炉点餐 → 左边圆桌吃串 → 烤炉加餐 → 圆桌吃加的餐 → 找老板结账。可以选二十或三十串，追加羊肉串或烤馒头，非力先结或三人凑钱。
- **海边**：中间长椅坐会儿，吹海风；左边栏杆可单独吹风，右边可扔石头。坐过之后可向右去网吧。
- **网吧**：走近中间三台电脑，选择位置与两轮配合。每次对话结束，再按 E 继续下一轮。最后一轮结束后，三个人聊着回家，进入结尾。

结尾可选择自由走走，或重新过这个晚上。向左返回旧地图，已完成的订单、结账和剧情仍会保留，不会重复计数。

## 这一版的变化

- 五张地图统一为经典掌机俯视像素风，保留高个子的非力、宽壮的孙天虎和圆胖的死猪。
- 非力使用偏深的暖棕肤色；保留“天黑了看不见你”的熟人玩笑。
- 四向行走、坐姿、孙天虎伸手和非力躲闪使用独立动画。
- 海水和烧烤烟气会动，桌子、电脑、长椅等独立物件与人物按位置显示遮挡。
- 平时只保留地点、当前任务和操作提示，互动时显示对话框。
- 延续已测试的跨场景变量、选择分支、加餐结账和回家结尾。

## 文件

- `game.json`：原生 GDevelop 工程，含五个场景与事件。
- `assets/`：完整本地 PNG 素材。
- `logic/dialogue-and-following.js`：场景中原生 JavaScript 事件的可读副本。改动副本不会自动同步回工程。
- `screenshots/`：真实游戏运行截图。
- `ART-DIRECTION.md`：已采用的画面规范。
- `VALIDATION.md` 与测试报告：验证范围和结果。

## 当前简化

朋友使用沿行走轨迹跟随的方式，还没有完整自主寻路与避让，转弯或靠近时可能贴近。LOL 是对话选择小游戏。暂无音乐、音效或跨次启动存档；关闭预览后，再次启动会从头开始。地图表现的是回忆中的氛围，不是实地测绘。
