# Memory World V0.8 · 青岛的那些夜晚

开头可以选非力、孙天虎或死猪，用三个人各自的视角过同一个晚上。沿用 V0.7 已确认的画风和五张地图，新增角色选择，并重写对话口气。

## 打开试玩

1. 完整解压 ZIP，保留 `game.json` 和旁边的 `assets/`。
2. 用 GDevelop 打开 `game.json`。
3. 从 **Select** 场景预览；默认起始场景已经设为 Select。
4. 按 **1 / 2 / 3** 选人，或用左右方向键切换，再按 **E / Enter** 开始。

全部图片在工程内，无需联网素材、额外插件或 API 密钥。使用 GDevelop 5.6.284 验证。

## 三个视角

| 视角 | 开场 | 你控制谁 |
| --- | --- | --- |
| 非力 | 家附近出门，和孙天虎碰头，再一起去商场 | 橙色上衣的非力 |
| 孙天虎 | 先在家附近等非力，碰头后一起去商场 | 青绿上衣的孙天虎 |
| 死猪 | 从商场交班开始，交完班再和前来的两人碰头 | 蓝色保安服的死猪 |

当前角色的名字后标有“你”。另外两人按照各自的身份跟随或等待，名字和模型不会互换。

三个视角共享这一晚的主路线，各有不同的开场、观察、玩家回应和回家结尾。玩家点餐、扔石头、选择游戏位置或说“我先结”时，由当前角色行动；小记会记住实际付款人。死猪视角里，非力和孙天虎在家附近的碰面发生在画面外。

## 对话改动

平时称呼非力，偶尔在夜间玩笑里叫黑力。死猪的话缩短，也减少主动插话，通常只简短催一句。非力和孙天虎之间改用“你他妈别叭叭”“你他妈手别欠”“我是你爹”等熟人间笑着回骂的口气。

孙天虎视角按 Q 可以主动闹非力；非力视角可以躲开或骂回去；死猪视角可以看他俩闹，或者催他们走。打闹不抢走角色控制，也不移动玩家的碰撞位置。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 控制当前角色行走 |
| E / 空格 / Enter | 互动、继续对话；安静坐着时起身 |
| 1 / 2 / 3 | 选对话选项 |
| Q | 当前视角的打闹互动 |
| J | 当前角色的今晚小记 |
| R | 确认是否清空进度并重新选人 |

对话和坐着时暂停移动。长椅对话结束后可以一直坐着，按 E 再起身。R 在正式对话和坐着时不会打断当前互动。

## 主路线

非力 / 孙天虎：家附近碰头 → 商场接死猪。

死猪：商场交班 → 和非力、孙天虎碰头。

随后：烤炉点串 → 左边圆桌吃串 → 烤炉加餐 → 圆桌吃加餐 → 找老板结账 → 海边长椅坐会儿 → 吹风 / 扔石头 → 网吧三台电脑 → 选择位置与两轮配合 → 各自视角的回家结尾。

网吧每段对话结束后，再靠近中间电脑按 E 继续下一轮。结尾可自由走走，或换个视角重新过这一晚。返回旧地图保留当前视角和已完成任务；重新选人会清空本轮进度。

## 文件与简化

`game.json` 是原生工程；`assets/` 是本地图片；`logic/` 是原生 JavaScript 事件的可读副本，改副本不会自动同步到工程。截图与验证报告随包附带。

朋友仍为轨迹跟随，没有完整自主寻路与避让。LOL 是选择式小游戏。暂无音乐、音效和跨次启动存档；关掉预览后重新启动会回到角色选择。三种视角是同一晚的不同体验，不是三套完全独立的长篇故事。
