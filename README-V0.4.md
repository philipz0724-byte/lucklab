# Memory World V0.4《青岛的那些夜晚》

这是可以直接用 GDevelop 打开、预览和继续编辑的原生游戏工程。

## 打开和试玩

1. 将 ZIP **完整解压**到一个文件夹，保持 `game.json` 和 `assets` 文件夹在一起。
2. 在 GDevelop 选择「文件 → 打开」，选解压后的 `game.json`。如果从主页操作，选择「打开项目」→「打开本地文件」。不要直接选 ZIP。
3. 打开 **Mall（商场）** 场景，点「预览」。第一次从 Mall 开始，才能走完整个夜晚。

已使用本机 **GDevelop 5.6.284** 的原生编译器编译，并用其真实游戏运行时走通四幕。无需额外插件、联网资源、API 密钥或账号登录。

## 操作

| 按键 | 用途 |
| --- | --- |
| WASD / 方向键 | 行走 |
| E / 空格 / Enter | 互动、继续对话 |
| 1 / 2 / 3 | 选择对话分支；主键盘和数字小键盘均支持 |
| J | 今晚的小记 |
| R | 打开重玩确认；1 继续，2 清空本轮进度并重玩 |

走近人物或地点，画面下缘会显示 `[ E ]` 提示。对话期间人物暂停走动；数字选项出现时按对应数字继续。

## 四幕流程

1. **商场**：先找壮实的朋友，再到门前接胖胖的保安朋友下班；人齐后往右去烧烤。
2. **路边烧烤**：到烤炉前点肥瘦相间的羊肉串，再到左侧小圆桌吃串、互损；吃完往右去海边。
3. **海边**：到中间栏杆旁吹风。合照、打水漂都可选；玩够后向右去网吧。
4. **网吧**：走到中间一排电脑旁，选上路、打野或下路，再做两回合互动。每回合对话结束后再按 E 继续这局，最后进入结尾。

从第二幕起，可以从左边返回前一张地图。主线、分支和回忆不会因来回切场景丢失。7 项回忆包括：碰面、接下班、羊肉串、海风、合照、打水漂、开黑。无需收齐可选回忆也能完成。

## 本版范围与简化

- 四张原创像素地图、三个体型不同的伙伴、四向行走帧、可碰撞的建筑/桌椅/边界、完整中文对话和温暖结尾。
- 朋友沿玩家已走过的轨迹跟随；进入新场景时重新集合。这是轨迹跟随，尚无独立寻路、避让和自由活动 AI，集合或急转弯时可能短暂靠得很近。
- LOL 是角色选择和两回合文字互动，结果会随选择变化；没有完整 MOBA 战斗，也未使用英雄联盟美术或音频。
- 本版没有配音、音乐和跨次启动存档。全局变量在**本次游戏运行期间**跨场景保留；关闭预览后从头开始。
- 地图根据用户确认的回忆做概括式创作，并非实际商场或海边地形的测绘复原。朋友使用体型称呼，未虚构真实姓名。

## 工程结构

- `game.json`：完整 GDevelop 项目。4 个真实场景、38 个图片资源、56 条原生事件条目。
- `assets/`：全部图片，均为相对路径，无远程资源依赖。
- `logic/dialogue-and-following.js`：对话/跟随事件的便于阅读副本。**运行时使用的是 game.json 各场景内的 JavaScript 事件**，修改这个副本不会自动同步工程。
- `VALIDATION.md` 与 `playtest-report.json`：检查范围与实测结果。

沿用 V0.3 工程的 Sprite、Text、TopDownMovement、SeparateFromObjects、NumberVariable、SetNumberVariable、Scene JSON/事件形式。新增对话和跟随使用 GDevelop 原生 JavaScript 事件；场景切换仍由可视化事件中的 Scene 动作执行。

代码和原创像素素材为本项目制作，可继续修改和使用。GDevelop 引擎及其第三方库不包含在此原生工程 ZIP 中；若自行导出游戏，请保留引擎要求的许可证。LOL / 英雄联盟名称属于其权利人，本项目为私人回忆题材原型，与其官方无关。
